# [Ai Sci Article Navigator](https://github.com/AlexPritchin/ai-sci-articles-navigator-project)
<p align="left"> <a href="https://github.com/AlexPritchin/ai-sci-articles-navigator-project"> <img src="https://user-images.githubusercontent.com/33416429/92813512-27f0bb80-f376-11ea-8562-ee2b3e416aec.png" width="150" ></a>
</p>
RAG-system based on Telegram Bot for science article uploading, translation and analysis.

A RAG-based Telegram assistant that translates and retrieves technical documentation using the Gemini API and ChromaDB, designed for high-performance and asynchronous query processing. It supports dialog memory and summary questions by LlamaIndex usage. It also is able to answer general science related questions.

The project was built with the help of Gemini and elements of vibe coding using Gemini.

Technologies used:
* FastAPI
* Aiogram
* Gemini API
* ChromaDB
* LlamaIndex
* GeminiEmbedding
* HuggingFaceEmbeddings

[Link to live demo](https://t.me/ai_sci_article_navigator_bot)
